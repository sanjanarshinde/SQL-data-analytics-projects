# Amazon Sales Analysis – SQL Project

## Project Overview

This project focuses on analyzing Amazon sales data using SQL to understand sales performance, customer behavior, product performance, order trends, payment methods, and seller performance.
The project covers the complete SQL analysis process, starting from data exploration and data quality checks to basic, intermediate, and advanced SQL analysis.

## Dataset

The dataset contains Amazon sales transaction data with information such as:

- Order ID
- Order Date
- Customer ID & Customer Name
- Product ID & Product Name
- Category
- Brand
- Quantity
- Discount
- Tax
- Shipping Cost
- Total Amount
- Payment Method
- Order Status
- City
- State
- Country
- Seller ID

## SQL Analysis Covered

### 1. Data Exploration
- Understanding the dataset
- Checking records and columns
- Exploring distinct values
- Understanding sales and order data

### 2. Data Quality Analysis
- Identifying missing values
- Checking duplicate records
- Checking inconsistent or invalid data
- Validating important columns

### 3. Sales Analysis
- Total sales
- Total orders
- Total quantity sold
- Year-wise sales
- Month-wise sales
- Sales by category
- Sales by product
- Sales by brand

### 4. Customer Analysis
- Customer-wise sales
- Customer order frequency
- Customer purchase behavior
- Identifying high-value customers

### 5. Product & Category Analysis
- Category-wise sales
- Product-wise sales
- Quantity sold by category
- Quantity sold by product
- Top-performing products

### 6. Payment Analysis
- Sales by payment method
- Order count by payment method
- Quantity sold by payment method

### 7. Seller Analysis
- Seller-wise sales
- Seller-wise order count
- Seller-wise quantity sold
- Identifying top-performing sellers

### 8. Advanced SQL Analysis
The project also uses advanced SQL concepts such as:

- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- CASE statements
- Aggregate Functions
- GROUP BY and HAVING
- Date Functions

## Tools Used

- PostgreSQL
- SQL
- VS Code

## Objective

The main objective of this project is to use SQL to transform raw sales data into meaningful business insights and demonstrate practical SQL skills through a complete end-to-end analysis.
